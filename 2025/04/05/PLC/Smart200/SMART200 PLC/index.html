# 一、电气基础知识

# 1、电

  • 直流 DC（Direct Current）：电流通过导体流动，电流的大小和方向都不随时间变化
    手机充电器

  • 交流 AC (Alternating Current)：大小和方向随时间周期性变化（正弦函数）
    屋里的灯，空调
    我国交流电（220v,50HZ 工频）；每个国家不一样

  • PLC——AC220V——AC380V 电机转

  • DC24V（直流 24V）

# 2、AC 交流电

  • 单相：一根火线 L：火 N：零
  • 三相：三根火线 L1 L2 L3
    任何一个电路不管直流交流，必须包含
  • 电源
  • 导线
  • 开关
  • 负载（用电器）
    左零右火
    电流从高往低流

# 课后习题（点动）

要求：按下按钮 SB1，电机转，松开 SB1，电机停止转动。

  • 看交流还是直流电？是三相还是单相

电机：380V（三相），50hz，30w
三相：L1 L2 L3 任意两根之间电压是 380V
按钮：SB
常开（Normal Open）：NO，常态下为断开状态（关闭）
常闭 (Normal Close)：NC，常态下为闭合状态（打开）

  • 逆变电源：AC220——AC380；单相 —— 三相
  • 空气开关：QF

又名空气断路器，是断路器的一种。是一种只要电路中电流超过额定电流就会自动断开的开关。空气开关是低压配电网络和电力拖动系统中非常重要的一种电器，它集控制和多种保护功能于一身。除能完成接触和分断电路外，尚能对电路或电气设备发生的短路、严重过载及欠电压等进行保护，同时也可以用于不频繁地启动电动机。

  • 交流接触器 KM：

交流接触器的工作原理是利用电磁力与弹簧弹力相配合，实现触头的接触和分断的。交流接触器有两种工作状态：失电状态（释放状态）和得电状态（动作状态）。
分为三部分：线圈，主触点，辅助触点

  • 总结：线圈得电，常开吸合，常闭断开；线圈失电：所有常开常闭复位
    复位：即常开恢复为常开，常闭恢复为常闭。
