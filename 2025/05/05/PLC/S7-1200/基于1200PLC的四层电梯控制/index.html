# 绪论引言

电梯是安装在建筑物内的一种交通工具，是为了满足人们对于垂直运输的需要而建立的。在现代社会，电梯就如同汽车、轮船一般不可或缺。随着城市建设的不断发展，楼群建筑不断增多，电梯在当今社会的生活中有着广泛的应用。如今，电梯的使用情况已成为衡量现代化发展程度的一种标志，从某种意义上说，电梯也成为研究一个城市中居民生活状态的最完美空间。而电梯作为一种公共交通工具，安全性能显得尤为重要，因为只有安全运行才能够使乘客对电梯产生信任感。随着高层建筑的不断出现，人们对电梯系统的性能要求也越来越高，不单单是安全性，还包括舒适度等方面。
电梯作为楼群建筑中垂直运行的交通工具已与人们的日常生活密不可分。电梯实际上是一个人机交互式的控制系统，单纯用顺序控制或逻辑控制是不能满足控制要求的，因此，大部分电梯控制系统都采用随机逻辑方式控制。目前电梯的控制普遍采用了两种方式，一是采用微机作为信号控制单元，完成电梯信号的采集、运行状态和功能的设定，实现电梯的自动调度和集选运行的功能，拖动控制则由变频器来完成；第二种控制方式用可编程控制器（PLC）取代微机实现信号集选控制。从控制方式和性能上来说，这两种方法并没有太大的区别。国内厂家大多选择第二种方式，其原因在于生产规模较小，自己设计和制造微机控制装置成本较高；而 PLC 可靠性高，程序设计方便灵活，抗干扰能力强、运行稳定、可靠性高等特点，所以现在的电梯控制系统广泛采用可编程控制器（PLC）来实现。

# 控制系统设计与实现

# 2.1 控制要求

当电梯停于 1F，2F 或 3F 时，高于其当前停靠楼层单个呼叫或者同时呼叫时，按照高低顺序上行。在上行过程中若存在下行呼叫，优先执行上行过程。
当电梯停于 4F，3F 或 2F 时，低于其当前停靠楼层单个呼叫或者同时呼叫时，按照高低顺序依次下行停靠 3S。在下行过程中若存在上行呼叫优先执行下行过程。电梯停于某层时，数码管应显示该层的楼层数。

# 2.2 控制方案及流程图

本项目要实现一个安全、高效的电梯运行方案。系统通过响应内呼和外呼请求，使电梯到目标楼层，并在到达后停靠，同时确保电梯门的安全操作。控制方案涵盖了开关门设计、楼层停靠逻辑、内部和外部呼叫处理，以及上下行控制设计，并通过仿真测试验证了其有效性。

# 3.1 开关电梯门设计

系统在接收到停靠等待信号后，首先设置开门中和上客标志。接着，利用定时器 TON，当开门中信号激活时，1 秒后触发开门操作。门的开启由自动和手动开门信号以及开门限位信号共同控制。门完全打开后，若开门限位信号被触发，系统将再次启动定时器，1 秒后开始关门。关门操作同样由自动和手动关门信号及关门限位信号控制。关门完成后，经过 2 秒的延时，系统更新状态，增加特定值并结束等待状态。当门的开关操作完全结束，系统将复位开门中信号，并设置开关门完成标志。最后，3 秒后，系统复位上客标志和开关门完成标志，准备进行下一轮操作。

# 3.2 楼层停靠设计

通过检测楼层指示信号（如内呼 1 楼、2 楼、3 楼、4 楼）和相应的平层信号（如平层 1M、2M、3M、4M），来激活对应的楼层指示。同时，通过上升指示和下降指示来控制电梯的运行方向。此外，“mydb”. 停靠等待和 "mydb". 等待结束信号用于管理电梯在停靠时的逻辑，确保电梯在接收到新的请求前已经完全停止并准备好。

# 3.3 内外部呼叫设计

内部呼叫设计：
电梯对 1 楼至 4 楼的内呼请求作出响应。当相应的内呼楼层信号（如 1 楼的 % M0.4、2 楼的 % M0.5、3 楼的 % M0.6、4 楼的 % M0.7）为真，且电梯已到达该楼层（如 1 楼的 % M0.0、2 楼的 % M0.1、3 楼的 % M0.2、4 楼的 % M0.3），并且电梯不在等待状态（“mydb”. 停靠等待为假），电梯的启动逻辑被激活。电梯将保持运行状态，直至对应的内呼楼层指示信号（如 1 楼的 % M10.4、2 楼的 % M10.5、3 楼的 % M10.6、4 楼的 % M10.7）为真，触发停止条件，使电梯停止。通过启保停功能块，确保电梯在接收到楼层呼叫请求时启动，并在到达目标楼层后停止，有效防止电梯在未到达目标楼层前意外停止，同时确保服务完成后能及时响应其他楼层的呼叫。
外部呼叫设计：
当相应的外呼信号被激活，且电梯不在当前楼层，并且电梯不在相反方向的运行状态，则激活相应的外呼上行或下行指示。
1 楼外呼上行与 4 楼外呼下行程序段一样。
2 楼外呼上行与与 2 楼外呼下行，3 楼外呼上行，3 楼外呼下行的程序段一样。

# 3.4 上下行控制设计

电梯控制系统根据内呼和外呼的楼层指示信号，结合上次层记录与当前楼层的比较结果，以及上升和下降的极限标志位，来决定激活相应的上升或下降指示位，以及上客标志位，以实现电梯的自动楼层响应和运行。

# 5 结 论

本项目旨在设计并实现一个基于可编程控制器（PLC）的四层电梯控制系统。通过对电梯控制要求的深入分析和系统设计，我们成功构建了一个能够满足现代电梯安全、高效运行需求的控制方案。
在控制要求方面，定义了电梯在不同楼层停靠时的响应策略，包括上行和下行过程中的呼叫处理逻辑，以及电梯门的开关控制流程。通过 I/O 分配表，为电梯的各个控制信号提供了明确的输入输出接口，为后续的硬件连接和程序编写奠定了基础。
在系统设计方面，将电梯的控制流程分解为开关门设计、楼层停靠设计、内外部呼叫设计、上下行控制设计等模块。通过仿真测试验证了设计的准确性和可靠性。
仿真测试阶段，我们通过模拟电梯的实际运行情况，对电梯控制系统进行了全面的测试。测试结果表明，电梯能够根据乘客的呼叫请求，准确无误地响应并执行相应的楼层停靠和门控制操作，验证了我们设计的控制系统的有效性和实用性。
综上所述，本项目成功实现了一个基于 PLC 的四层电梯控制系统，在安全性、可靠性和用户舒适度方面均达到了预期的设计目标。通过本项目的设计和实施，我深入理解了 PLC 在复杂控制系统中的应用，为未来在自动化领域的进一步学习和研究打下了坚实的基础。
